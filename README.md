# Ciudadanos Invisibles
[Español](README.es.md) | English
> A website for Ciudadanos Invisibles, a clothing company created to raise awareness about informal settlements in Colombia


*Disclaimer: created for a Spanish project, not a real company*

## Pages

* **About Us:** Learn about our cause, the challenges faced in informal settlements, and its relevance globally
* **Products:** Buy shirts or tote bags to support our cause
* **Donate:** Donate to the organization Techo instead of buying a product

## Tech Stack

* **Markup Language:** HTML5
* **Style and Design:** CSS
* **Fonts:** Google Fonts (*Allura*)
